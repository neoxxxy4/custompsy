# Задача: редизайн главной — «День» как центр системы (по прилагаемому макету)

## Контекст проекта

React + TypeScript + Vite + Tailwind CSS 3.4. Личная операционная система
(планирование дня, чек-листы, заметки, дневник, блог, граф, баланс, роадмапа, календарь).

Навигация — без роутера: стейт `view` в `src/App.tsx`, тип ViewId:
'hub' | 'day' | 'graph' | 'checklists' | 'notes' | 'diary' | 'balance' | 'roadmap' | 'planning' | 'calendar' | 'blog'.
Сейчас наверху есть TopBar с кластерами-выпадайками (`src/components/TopBar.tsx`).

Данные: облачная синхронизация через tRPC, фронтенд работает через хук
`useLS<T>(key, initial)` из `src/views/practice/store.ts` (внутри — sync-движок
`src/lib/sync.ts`: localStorage как зеркало + сервер как источник истины).
Ключи данных:
- `aod2-day-<YYYY-MM-DD>` — чек-листы дня: DayInstance[] { iid, templateId, title, time, color, collapsed, items: {id,text,done}[] }
- `aod2-templates` — пользовательские шаблоны чек-листов
- `aod2-goals-<date>` — цели дня: { text, done }[]
- `aod2-sched-<date>` — отметки блоков расписания (legacy)
- `aod2-schedblocks-<date>` — НОВЫЙ ключ: редактируемое расписание дня
  { id, time, what, color?, done }[]
- `aod-cal` — пользовательские события календаря { date, title, color, kind }
- `aod2-notes` / `aod2-folders` — заметки и папки
- `aod2-diary` — дневник Record<date, entry>
- `aod2-blog` — посты
- `aod-balance` — number[6]

Дизайн-токены (src/index.css): фон --bg:#050100, панели .panel/.glass,
текст --text/#cbc6b9, --light:#e9e7e2, --muted:#8a8578, акцент --accent:#2474ff,
линии --line / --line-strong. Шрифты: Oswald (.display), Inter, JetBrains Mono
(.mono-label — uppercase micro-labels). Классы анимации: .rise, .fadein.
Цвета сил: --f-discipline/--f-environment/--f-metacog/--f-emotions/--f-neuro/--f-boundaries.

## Что делать

### 1. Главная = «День»
Дефолтный view — 'day' (не 'hub'). Хаб остаётся доступным как пункт «Обзор».

### 2. Левая рейка навигации (десктоп)
Фиксированный сайдбар ~230px слева, как в макете:
- логотип «А» в синем квадрате сверху
- список сервисов: Сегодня, Календарь, Чек-листы, Заметки, Дневник, Блог, Граф,
  Баланс, Роадмапа, Планирование (+ Обзор внизу или по клику на лого)
- у каждого пункта: маленькая линейная иконка, подпись, справа микро-статус
  из живых данных (чек-листы «3/12», дневник «записано/не записано», заметки —
  количество, блог — количество, календарь — события сегодня, граф «v3.0»)
- активный пункт — синяя подсветка + подчёркивание
- «Чек-листы»/«Заметки»/«Дневник» ведут в существующий модуль Практика
  на соответствующую вкладку (view 'checklists'/'notes'/'diary', уже работает)
- на мобильном (<lg) сайдбар скрывается, остаётся существующий TopBar

### 3. Тонкий статус-бар сверху (десктоп)
Вместо TopBar: хлебные крошки «Главная / <текущий раздел>» слева,
справа живая строка дня: кольцо прогресса + «62% · <текущий/следующий блок
расписания> · <цели n/m> · v3.0», клик ведёт в «День».

### 4. Новый layout модуля «День» (строго по макету)
Убрать гигантский заголовок «СЕГОДНЯ». Компактная строка:
«СЕГОДНЯ · <дата> · <день недели>» мелким mono-label.

Ряд 1 — две панели рядом (grid 2 колонки на десктопе):
- **Цели дня** (слева): пронумерованные строки 01–04, у каждой чекбокс,
  редактируемый текст (инпут), кнопки редактирования/удаления (иконки ✏️ ✕,
  появляются по hover). Внизу пунктирная кнопка «+ добавить цель».
  Количество целей не зашито — можно добавлять/удалять.
- **Расписание** (справа): вертикальный таймлайн с линией и точками.
  Каждая строка: время (редактируемое, маленький инпут HH:MM), название
  (редактируемое), чекбокс выполнения, удаление по hover.
  Внизу «+ добавить событие». Данные — НОВЫЙ ключ `aod2-schedblocks-<date>`:
  при первом открытии дня сидится из WEEK_TEMPLATE (шаблон будня из
  `src/data/system.ts`) + переносятся отметки из legacy-ключа `aod2-sched-<date>`.
  События календаря на сегодня показывать отдельными строками с пометкой
  «из календаря» (не редактируются здесь).

Ряд 2 — **Чек-листы дня** на всю ширину: сетка карточек (2–3 колонки),
каждая сворачиваемая, с прогрессом «3/5», пункты кликабельны, пункты можно
добавлять (инпут внизу карточки) и удалять (✕ по hover), карточку можно
убрать из дня. Пунктирная карточка «+ Добавить чек-лист · из шаблона или
новый»: открывает панель выбора существующих шаблонов (копией, шаблон не
меняется) + форму создания нового шаблона (название, подпись, цвет из палитры,
пункты списком) — логика уже есть в `src/views/practice/ChecklistsTab.tsx`,
вынести в переиспользуемый компонент и использовать в обоих местах.

Правая колонка (~320px):
- **Прогресс дня**: большое кольцо с процентом и «done/total».
  Считается из целей + блоков расписания + пунктов чек-листов.
- **Быстрые заметки**: 3 последние заметки из `aod2-notes` (папка «Входящие»),
  инпут «+ новая заметка» (создаёт заметку в inbox), клик по заметке →
  переход в «Заметки».

### 5. Принцип «всё редактируется»
Цели, события расписания, пункты чек-листов — редактируются инлайн прямо
на месте. Это конструктор дня, а не read-only дашборд.

## Ограничения
- Не ломать синхронизацию: все данные только через useLS (он сам пишет
  на сервер и в localStorage). localStorage напрямую не трогать.
- TopBar оставить для мобильной версии; его расчёт статуса обновить под
  новый ключ расписания `aod2-schedblocks-<date>` (с fallback на старый).
- Стили — только существующие токены и классы дизайн-системы, никаких новых
  цветов и шрифтов.
- TypeScript без any, `npm run check` и `npm run build` должны проходить.

## Критерии приёмки
1. При открытии приложения сразу виден «День» в новом layout.
2. Сайдбар слева со всеми сервисами и живыми микро-статусами; переходы работают.
3. Цели: добавить/редактировать/удалить/отметить — всё сохраняется после перезагрузки.
4. Расписание: добавить событие, изменить время/название, удалить, отметить —
   сохраняется; завтра день снова сидится из шаблона недели.
5. Чек-листы: добавить из шаблона и создать новый шаблон можно прямо со
   страницы «День».
6. Быстрые заметки справа создаются и попадают в модуль «Заметки».
7. Прогресс-кольцо и статус-бар сверху показывают одни и те же цифры.
