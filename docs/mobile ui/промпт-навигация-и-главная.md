# Промпт для кодового агента: новая навигация + главная «Сегодня» (тёмная ТГ-тема)

К сообщению приложены 7 макетов — это целевой вид (не 1:1 попиксельно, а по структуре и поведению):

| Файл | Экран |
|---|---|
| комбо-три-круга.png | Главная «Сегодня» — базовое состояние |
| комбо-сегодня-раскрыт.png | Главная — чек-лист раскрыт аккордеоном |
| комбо-заметка-окно.png | Заметка открыта мини-окном (шторкой) поверх «Сегодня» |
| комбо-записи.png | «Записи» → папка «Заметки» |
| комбо-списки.png | «Записи» → папка «Списки» |
| комбо-дневник.png | Режим погружения (редактор записи/дневника) |
| комбо-блог.png | «Блог» — отдельная вкладка |

---

## 1. Контекст проекта

- Стек: React 19 + TypeScript + Vite + Tailwind CSS + shadcn/ui. Dev-порт 3000 (не менять).
- Переключение экранов — через состояние (`ViewId` в `App.tsx`), НЕ через роутер-пути.
- Все данные хранятся через хук `useLS(key, initial)` из `src/views/practice/store.ts` (он сам синхронизирует с облаком).
- **ЗАПРЕЩЕНО менять ключи данных и сигнатуру `useLS`** — у пользователя уже есть данные. Существующие ключи:
  - `aod2-day-<дата>` — чек-листы дня (DayInstance: items с done)
  - `aod2-templates` — шаблоны чек-листов
  - `aod2-goals-<дата>` — цели дня
  - `aod2-schedblocks-<дата>` — расписание дня (блоки с временем; если нет — fallback `aod2-sched-<дата>`)
  - `aod2-notes`, `aod2-folders` — заметки и папки
  - `aod2-diary` — дневник
  - `aod2-blog` — посты блога
  - `aod-cal`, `aod-balance` — календарь, баланс
- Существующие вьюхи заметок/списков/дневника (`ChecklistsView` и т.д.) **переиспользовать**, данные не мигрировать.
- Если в проекте есть левая панель или верхний TopBar — они заменяются нижним меню из этого ТЗ.

## 2. Дизайн-токены (тёмная Telegram-тема)

Все цвета — через CSS-переменные (не хардкодить в компонентах), чтобы работал существующий переключатель тем:

```
--bg:        #0E1621   /* фон приложения */
--surface:   #17212B   /* карточки */
--surface-2: #1E2C3E   /* вложенные элементы, ховер */
--text:      #FFFFFF
--text-2:    #E4E6EA
--muted:     #8A94A6
--accent:    #2AABEE   /* синий ТГ: активные элементы, FAB, ссылки */
--success:   #4FAE4E   /* галочки */
/* кольца прогресса: */
--ring-goals:      #2AABEE   /* цели — синий */
--ring-schedule:   #2BD9C7   /* расписание — бирюзовый */
--ring-checklists: #A06CFF   /* чек-листы — фиолетовый */
```

Радиусы: карточки 16–20px, чипы-папки — полностью скруглённые (pill). Шрифт — системный/Inter, заголовки экранов ~28px bold, карточки — плотные (padding 12–16px, мелкие шрифты 13–15px).

## 3. Нижнее меню — `BottomNav`

Новый фиксированный компонент внизу экрана, виден на всех корневых экранах:

- 5 разделов: **СЕГОДНЯ** (иконка home/calendar) · **ЗАПИСИ** (square-pen) · **БЛОГ** (notebook-pen) · **ПУТЬ** (compass/mountain) · **СИСТЕМА** (settings/gear).
- Активный пункт — `--accent`, неактивные — `--muted`.
- Фон: `--surface` с верхней тонкой границей или blur.
- Стирает/заменяет текущую верхнюю навигацию на корневых экранах. Верхний TopBar с кластерами больше не нужен (всё, что там было, распределяется: Путь → вкладка «Путь», Система → вкладка «Система»).

Изменения в `ViewId`: добавить `'records'` (Записи) и `'today'` (или оставить существующий id главной). Отдельные пункты меню для чек-листов/заметок/дневника убираются — они живут внутри «Записей».

## 4. Главная — `TodayView` (экран «Сегодня»)

Компактный дашборд: при обычном наполнении всё влезает в один экран. Сверху вниз:

### 4.1 Шапка
«Сегодня» (~28px bold) + дата мелким серым рядом, справа — колокольчик (пока заглушка).

### 4.2 Карточка «Прогресс дня» — ТРИ КОЛЬЦА (см. комбо-три-круга.png)
Три маленьких SVG-кольца в ряд, равные отступы, не наслаиваются:

- **Цели** — цвет `--ring-goals`, процент = done/total из `aod2-goals-<today>`, под кольцом: иконка-мишень, «Цели», дробь «2/4».
- **Расписание** — цвет `--ring-schedule`, процент = выполненные блоки из `aod2-schedblocks-<today>`, подпись «Расписание», «1/3».
- **Чек-листы** — цвет `--ring-checklists`, суммарно по всем спискам дня из `aod2-day-<today>` (все items done/total), подпись «Чек-листы», «5/13».

Процент — внутри кольца, подписи — снизу. Если данных нет (деление на 0) — кольцо пустое, «0%», дробь «0/0» не показывать, показать «—».
**Тап по кольцу** — плавный скролл к соответствующей карточке ниже + короткая подсветка карточки (flash по рамке ~600ms).

### 4.3 Карточка «Цели» — СТАТИЧНАЯ высота
- Заголовок «Цели», справа ссылка «+ добавить» (accent).
- Фиксированная высота: видно ~4 строки. При переполнении — **внутренний вертикальный скролл карточки** (overflow-y-auto, тонкий скроллбар), карточка НЕ растёт, страница не прыгает.
- Строка цели: чекбокс (accent при отметке, текст зачёркивается) + текст. Тап по тексту — inline-редактирование. «+ добавить» — новая пустая строка в режиме редактирования.
- Данные: `aod2-goals-<today>` через useLS.

### 4.4 Карточка «Расписание» — СТАТИЧНАЯ высота
- Заголовок «Расписание», справа «+ событие».
- Строки: время (accent, mono) — точка — название. Видно ~3 строки, дальше внутренний скролл.
- Добавление/редактирование — inline (время + название). Данные: `aod2-schedblocks-<today>` (fallback на `aod2-sched-<today>`).

### 4.5 Карточка «Чек-листы» — АККОРДЕОН (см. комбо-сегодня-раскрыт.png)
- Свёрнутая строка списка: цветная иконка + название + тонкий прогресс-бар + счётчик «3/5» + chevron-down.
- Тап — раскрывает список прямо на месте: пункты с чекбоксами (отмечают сразу, пишут в `aod2-day-<today>`), chevron-up. Раскрытыми могут быть несколько списков (массив expandedIds в локальном state).
- Раскрытие отталкивает карточку «Заметки» вниз — появляется небольшой скролл страницы, это ОК.
- Источник списков: шаблоны из `aod2-templates` + инстанс дня `aod2-day-<today>` (как сейчас работает DayView — переиспользовать логику seedDay/instantiate).

### 4.6 Карточка «Заметки»
- Заголовок «Заметки», справа «все →» — переход во вкладку «Записи» с активной папкой «Заметки».
- Две последние заметки из `aod2-notes`: иконка + одна строка заголовка (ellipsis).
- **Тап по заметке → шторка `NoteSheet`** (см. п. 5). Полноэкранного перехода НЕТ.

### 4.7 FAB на главной
Не нужен — «+ добавить»/«+ событие» живут внутри карточек.

## 5. `NoteSheet` — заметка мини-окном (см. комбо-заметка-окно.png)

- Bottom sheet: поднимается снизу на ~70–75% высоты, скруглённый верх (rounded-t-2xl), drag-handle (серая пилюля по центру).
- За шторкой «Сегодня» видна сквозь затемнение (bg-black/60 backdrop).
- Закрытие: свайп вниз за шторку, тап по затемнённой зоне, кнопка «Закрыть» (accent, справа внизу).
- Внутри: заголовок заметки, дата мелким, чип папки/тега, текст (чтение; редактирование — по тапу на текст, опционально).
- Нижняя панель действий: закрепить (звезда), поделиться, удалить (корзина), «Закрыть».
- Реализация: фиксированный overlay + translate-y анимация (200–250ms ease-out). BottomNav остаётся виден под/над шторкой — не критично, по макету виден.

## 6. «Записи» — `RecordsView` (см. комбо-записи.png, комбо-списки.png)

### 6.1 Шапка
Заголовок «Записи» (~28px bold) + иконка поиска справа (поиск по заметкам/спискам/дневнику; можно отложить, иконку оставить).

### 6.2 Папки-чипы (верхняя плашка)
Горизонтальный ряд: **ВСЁ** · **ЗАМЕТКИ** · **СПИСКИ** · **ДНЕВНИК** (пользовательские папки из `aod2-folders` — следующим этапом, заложить возможность).
- Активный чип — залит `--accent`, белый текст; неактивные — обводка, `--muted`.
- Тап переключает; **свайп влево/вправо по области контента** листает папки (touch-handlers, без внешних библиотек).
- Состояние: `activeFolder: 'all' | 'notes' | 'lists' | 'diary'` в useState. При переходе с главной через «все →» — открывать сразу 'notes'.

### 6.3 Контент папок
- **ВСЁ**: общая лента — заметки, списки, записи дневника, отсортированные по дате обновления, с различимыми иконками типов.
- **ЗАМЕТКИ**: карточки заметок — цветная плитка-иконка слева, заголовок, 2 строки превью, дата/время справа, чип папки, звезда-закреп. Данные: `aod2-notes` (переиспользовать существующий код заметок).
- **СПИСКИ**: карточки чек-листов с прогресс-баром и счётчиком; развёрнутая карточка показывает пункты (как на главной, п. 4.5). Данные: `aod2-templates` + `aod2-day-<today>`.
- **ДНЕВНИК**: список записей из `aod2-diary`.

### 6.4 FAB «+»
Плавающая круглая кнопка `--accent` справа внизу над BottomNav. **Контекстная**: на «Заметки» — новая заметка, на «Списки» — выбор: из шаблона или новый список, на «Дневник» — запись за сегодня, на «Всё» — маленькое меню (заметка / список / запись в дневник).

### 6.5 Открытие элемента → режим погружения (см. комбо-дневник.png)
Тап по заметке/записи/списку: `selectedId !== null` → редактор на весь экран:
- Всё убирается: ни папок, ни BottomNav. Только: «←» (accent) слева, заголовок по центру, «⋯» справа (действия: закрепить/поделиться/удалить).
- Контент — редактор (textarea/существующие редакторы). У дневника: тег настроения + слайдер фокуса 0–10 (как в макете; если в данных нет — добавить поля опциональными).
- Внизу — маленькая плавающая пилюля из 3 иконок: **домой** (→ «Сегодня»), **папки** (назад к списку, = «←»), **микрофон** (пока заглушка: toast «Скоро» — задел под голосового агента).
- Жест «свайп от левого края вправо» = назад.

## 7. «Блог» — `BlogView` (см. комбо-блог.png)

Отдельная вкладка в BottomNav (не внутри «Записей»):
- Шапка «Блог» + иконка «новый пост» (compose) справа.
- Ряд из 3 статус-тайлов: постов / просмотров / черновиков (если счётчиков нет в данных — показать посты и черновики из `aod2-blog`, просмотры — «—»).
- Список карточек: цветная плитка-иконка, заголовок, 2 строки превью, строка статистики (глаз/сердце/коммент — если есть, иначе только дата), метка «ЧЕРНОВИК» (accent-чип) для неопубликованных.
- FAB «+» — новый пост. Данные: `aod2-blog`, редактор — переиспользовать существующий.

## 8. Вкладки «Путь» и «Система»

Без редизайна в этом ТЗ: существующие экраны (граф/роадмап/баланс/календарь/планирование) разместить под эти две вкладки как есть (Путь: граф, роадмап, баланс; Система: календарь, планирование, настройки/темы) — можно простым списком-меню или суб-табами, на усмотрение, главное — достижимость из BottomNav.

## 9. Критерии приёмки

1. `npm run check` (tsc) — без ошибок; `npm run build` — успешно.
2. Все прежние данные на месте: ключи localStorage/синка НЕ изменены, миграций нет.
3. Главная: при 4 целях, 3 событиях, 3 чек-листах, 2 заметках — всё видно без скролла страницы; при переполнении цели/расписание скроллятся ВНУТРИ своих карточек.
4. Три кольца показывают реальные проценты из данных и пересчитываются при отметках в любой карточке (реактивно, без перезагрузки).
5. Чек-листы раскрываются/сворачиваются аккордеоном, отметки сохраняются (600ms-дебаунс синка уже встроен в useLS — не сломать).
6. Заметка с главной открывается шторкой: за ней видно затемнённое «Сегодня», закрывается свайпом вниз и тапом по фону.
7. В «Записях» папки переключаются тапом и свайпом; FAB создаёт сущность текущей папки.
8. Режим погружения: при открытии записи видны только «←», заголовок, «⋯» и нижняя пилюля (домой/папки/микрофон-заглушка).
9. Навигация: BottomNav на всех корневых экранах, активный пункт подсвечен; старая верхняя навигация/сайдбар убраны.
10. Цвета — только через CSS-переменные; переключатель тем (если есть) продолжает работать.

## 10. Чего НЕ делать

- Не менять ключи данных, сигнатуру `useLS`, схему БД, файлы `api/`, `.env`, порт 3000.
- Не добавлять роутер-пути — навигация состоянием, как сейчас.
- Не тянуть тяжёлые библиотеки (sheet/свайпы — руками на CSS transitions + touch events).
- Не реализовывать голосовой агент и поиск — только иконки-заглушки.
